## 문서 관리 원칙

- 대표 README는 처음 방문한 사람이 1~2분 안에 이해할 수 있는 수준으로 유지합니다.
- 자주 바뀌는 명단·조직·프로젝트 상세 내용은 `docs/`에서 관리합니다.
- 같은 정보를 여러 파일에 중복 작성하지 않습니다.
- 프로젝트별 세부 기술문서는 각 프로젝트 저장소에서 관리합니다.
- 확정된 내용과 검토 중인 내용을 구분해 표시합니다.
