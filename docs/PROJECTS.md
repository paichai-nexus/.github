# NEXUS Projects

NEXUS의 공식 프로젝트는 코드 유무와 관계없이 **책임자, 현재 상태, 다음 목표와 기록**을 기준으로 관리합니다.

전체 프로젝트 현황은 [NEXUS Project Registry](https://github.com/paichai-nexus/nexus-project-registry)에서 확인할 수 있습니다.

## 2026년 최우선 프로젝트

### 🌱 [Smart Seedling AI](https://github.com/paichai-nexus/smart-seedling-ai)

> 작물 이미지와 환경 데이터를 모아 생육 상태를 관찰하는 스마트팜 프로젝트

Smart Seedling AI는 작물의 이미지와 온도·습도 같은 환경 정보를 수집하고, 이를 한 화면에서 확인할 수 있도록 만드는 프로젝트입니다.

앞으로 데이터가 충분히 모이면 이미지 분석 AI를 활용해 작물의 생육 상태나 이상징후를 찾는 기능으로 발전시키고자 합니다.

### 2026년 2학기 첫 번째 목표

1. 대상 작물을 정합니다.
2. 작물 이미지를 일정한 방식으로 촬영합니다.
3. 온도와 습도 등 기본적인 환경 정보를 수집합니다.
4. 수집한 정보를 저장합니다.
5. 웹 화면에서 이미지와 환경 정보를 확인합니다.
6. 실험 과정과 결과를 문서로 남깁니다.

### 전공별 역할

| 분야 | 함께할 수 있는 일 |
| --- | --- |
| 원예산림 | 대상 작물 선정, 생육 기준 정리, 실험 결과 확인 |
| 컴퓨터공학·소프트웨어 | 데이터 처리, 이미지 분석, 웹 화면 제작, 시스템 연결 |
| 전기전자 | 환경센서, 전원, 배선, 제어 장치 구성 |
| 드론로봇 | 촬영 방법과 자동화 적용 가능성 조사 |
| 건축·조경 | 온실, 재배공간, 식재환경과 이동 동선 검토 |
| IT경영정보 | 일정, 회의록, 예산과 활동 결과 정리 |
| 디자인·콘텐츠 | 프로젝트 소개자료, 발표자료와 사용 화면 디자인 |

### 현재 진행 상황

- `확정` — 2026년 2학기 NEXUS 최우선 프로젝트
- `진행 중` — 웹 화면과 데이터 저장 구조 개발
- `진행 중` — 전공별 역할과 참여자 조정
- `협의 중` — 실험공간과 교수님 자문
- `검토 중` — 대상 작물, 센서 종류, 필요 장비와 예상 비용
- `나중에 검토` — 자동제어, 드론 촬영, 논문·특허·공모전 참여

## 프로젝트 등록 원칙

```text
문제 정의
↓
Project Lead 확정
↓
Repository 생성
↓
README / Milestone 작성
↓
Project Registry 등록
↓
개발·연구·검증
↓
결과 기록 및 인수인계
```

회의에서 아이디어가 나왔다는 이유만으로 공식 프로젝트가 되지는 않습니다.

**Repository, Project Lead, Current Status, Next Milestone**이 확인되는 시점부터 공식 NEXUS 프로젝트로 관리합니다.

## 프로젝트 진행 방법

1. 비슷한 논문, 제품, 다른 학교 프로젝트와 공개자료부터 조사합니다.
2. 한 달 또는 한 학기 안에 실제로 만들 수 있는 작은 결과물부터 시작합니다.
3. 모든 과제에는 담당자와 마감일을 정합니다.
4. 진행 상황과 한계를 솔직하게 기록합니다.

### 상태 기준

| 상태 | 의미 |
| --- | --- |
| `아이디어` | 아직 생각을 정리하는 단계 |
| `준비 중` | 책임자, 참여자와 첫 목표를 정하는 단계 |
| `진행 중` | 실제 조사·개발·설계·실험을 진행하는 단계 |
| `확인 중` | 만든 결과물이 제대로 작동하는지 확인하는 단계 |
| `완료` | 결과물과 활동 기록을 정리한 상태 |
| `보류` | 필요한 조건이 갖춰질 때까지 기다리는 상태 |

프로젝트가 보류됐다고 해서 실패한 것은 아닙니다. 준비가 됐을 때 다시 시작하기 위한 선택입니다.

보다 구체적인 프로젝트 문서 기준은 [PROJECT_STANDARD.md](./PROJECT_STANDARD.md)를 따릅니다.
