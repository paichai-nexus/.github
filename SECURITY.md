# Security Policy

PAICHAI NEXUS repositories are student-led research and project repositories.

Do not publish:

- passwords, tokens, or API keys
- private personal information
- private institutional or company data
- credentials or internal network information
- sensitive research participant data
- data that cannot legally or ethically be made public

If sensitive information is accidentally committed, remove it from the repository history where necessary and rotate affected credentials immediately.

For security-sensitive reports, contact the repository maintainers privately rather than opening a public issue.
