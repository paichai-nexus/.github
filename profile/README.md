## About NEXUS

PAICHAI NEXUS는 배재대학교의 여러 전공 학생들이 하나의 문제를 함께 정의하고, 각자의 전공 역량을 연결해 실제 결과물을 만드는 **학생 주도 융합 프로젝트·R&D 동아리**입니다.

처음부터 완벽한 기술이나 큰 성과를 요구하지 않습니다. 아직 경험이 부족하더라도 기획·조사·제작·검증·발표의 전 과정을 직접 경험하고, 작은 목표라도 끝까지 완성하는 것을 중요하게 생각합니다.

NEXUS는 전공 수업에서 배운 내용을 실제 문제에 적용하는 것을 출발점으로 삼습니다. 학생들은 프로젝트에 따라 연구개발, 산업체험, 공모전·전시, 사업기획의 과정을 경험할 수 있습니다. 다만 모든 활동을 한꺼번에 추진하지 않고, 학기마다 하나의 우선 분야와 대표 프로젝트를 정해 집중합니다.

2026년 2학기에는 **R&D를 우선 활동으로 설정하고 Smart Seedling AI를 대표 프로젝트로 진행**합니다. 사업화·특허·논문·공모전은 처음부터 모든 프로젝트에 요구하지 않으며, 실제 결과물과 근거가 만들어진 뒤 가능성과 필요성이 확인되면 후속 단계로 검토합니다.

## What We Do

NEXUS의 활동은 다음 네 가지 트랙으로 구성됩니다.

### 1. Research & Development · 연구개발

전공 지식을 연결하여 실제 문제를 조사하고 기술이나 실험으로 검증합니다.

- 논문·학술자료·공개데이터·기존 제품 조사
- 소프트웨어·AI·센서·임베디드·로봇·공간 설계
- 최소 기능 제품 또는 실험용 시제품 제작
- 데이터 수집, 성능 확인, 사용자·도메인 검증
- 연구노트·기술문서·결과보고서 작성
- 가능성이 확인된 경우 논문·특허·후속 연구 검토

단순히 새로운 기술을 사용했다는 사실보다, 기존 방식과 어떤 차이가 있고 실제로 무엇을 검증했는지를 중요하게 봅니다.

### 2. Industry Experience · 기업·현장 체험

기업과 기관의 실제 업무가 어떤 방식으로 기획·개발·관리되는지 경험합니다.

- 기업·연구기관·현장 방문 및 실무자 인터뷰
- 현업 개발·연구·프로젝트 관리 방식 학습
- RFP, 사업제안서, 과업보고서, 연차보고서, 성과지표 등 실무 문서 체험
- 실무자의 특강·멘토링·기술 자문
- 기업이나 기관이 제시한 문제의 학생 수준 PoC 검토
- 현장 경험을 프로젝트와 진로 탐색에 연결

기업 연계는 취업이나 인턴십을 보장하는 활동이 아니라, 학생이 실제 산업의 문제와 업무 방식을 이해하기 위한 경험으로 운영합니다.

### 3. Project Challenge · 프로젝트·공모전·전시

학교와 지역사회의 문제를 주제로 팀을 구성하고, 정해진 기간 안에 결과물을 완성합니다.

- 교내외 공모전·해커톤·아이디어 경진대회 참여
- 전시·체험부스·발표·데모 운영
- 캠퍼스와 지역 문제를 해결하는 서비스·제품 기획
- 역할 분담, 일정관리, 발표와 피드백 경험
- 결과물의 코드·설계·문서·영상·포트폴리오 기록

수상 여부만을 목표로 하지 않고, 마감 안에 협업하여 완성하고 피드백을 다음 결과물에 반영하는 과정을 중요하게 생각합니다.

### 4. Business & Entrepreneurship · 사업기획·창업 탐색

연구나 프로젝트에서 실제 수요와 활용 가능성이 확인된 결과물은 사업 관점에서 추가로 검토할 수 있습니다.

- 사용자와 문제의 실제 수요 확인
- 시장·정책·경쟁 서비스 조사
- 서비스 모델과 운영방식 설계
- 예산·BOM·일정·성과지표 작성
- 교내외 지원사업과 창업 프로그램 탐색
- 기술사업화·지식재산권 가능성 1차 검토

사업화는 NEXUS의 모든 활동에 적용되는 기본 목표가 아닙니다. 작동하는 결과물과 사용자의 필요가 확인된 프로젝트만 별도의 사업기획 단계로 전환합니다.

### One Focus at a Time

네 가지 활동 트랙을 운영하더라도 한 프로젝트에서 모든 것을 동시에 수행하지 않습니다.

```text
학기 우선 분야 결정
→ 대표 프로젝트 선정
→ 조사와 작은 결과물
→ 제작·검증·기록
→ 성과에 따라 후속 트랙 선택
```

예를 들어 연구개발 결과에 실제 수요가 확인되면 사업기획으로 확장하고, 기업 자문이 필요하면 산업체험·멘토링과 연결합니다. 반대로 근거와 책임자가 없는 활동은 시작하지 않거나 준비 단계에 보관합니다.

```text
IDEA → RESEARCH → TEAM → BUILD → VALIDATE → RECORD
```

### 🌱 Smart Seedling AI

> 작물 이미지와 환경 데이터를 활용한 생육 관찰 및 스마트팜 연구 프로젝트

### 🍽️ Zero-Waste FoodTech

> 식품영양학과 × 외식조리학과 × 컴퓨터공학과

식재료를 촬영하여 종류와 상태를 확인하고, 먼저 소비해야 할 재료와 활용 가능한 레시피를 제안하는 프로젝트입니다. AI가 생성한 결과를 그대로 제공하지 않고 외식조리학과의 실조리와 식품영양학과의 영양·안전 검토를 거쳐 실제 활용 가능성을 검증합니다.

```text
식재료 촬영
→ 종류·상태 인식
→ 소비 우선순위 판단
→ 레시피 후보 추천
→ 외식조리 실조리·수정
→ 식품영양 영양·안전 검토
→ 사용자 평가와 결과 반영
```

- `현재 단계` — 참여자와 1차 실험 범위 정리
- `첫 결과물 후보` — 제한된 식재료를 대상으로 한 인식·레시피 추천 PoC와 실조리 평가 기록
- `검증 기준` — 인식 정확도, 조리 가능성, 영양 적절성, 사용자 만족도
- `확장 가능성` — 교내 공모전, 연구보고서, 음식물 낭비 저감 실험

그 밖의 아이디어는 책임자·참여자·첫 결과물·4주 계획이 마련될 때까지 내부 제안 목록에서 관리합니다. 준비되지 않은 아이디어를 진행 중인 프로젝트처럼 공개하지 않습니다.

## How We Work

### 1. 문제와 근거를 먼저 확인합니다

유사 논문·제품·다른 학교 사례를 조사하고, 기존 방식의 한계와 우리가 추가할 한 가지 차이점을 정리합니다.

### 2. 작은 결과물부터 만듭니다

전체 시스템보다 실제로 제작하고 검증할 수 있는 최소 기능이나 실험을 먼저 정합니다.

### 3. 프로젝트 책임자가 실행을 이끕니다

프로젝트 책임자가 목표·역할·일정을 정리하고, 운영진은 필요한 전공·공간·장비·문서·교수 자문을 연결합니다.

### 4. 상태를 정직하게 공개합니다

| 상태 | 의미 |
| --- | --- |
| `IDEA` | 아이디어 단계 |
| `PREPARING` | 책임자·참여자·첫 결과물 정리 중 |
| `ACTIVE` | 실제 활동 진행 중 |
| `VALIDATING` | 시제품·연구 결과 검증 중 |
| `COMPLETED` | 결과물과 기록 정리 완료 |
| `ON HOLD` | 조건이 갖춰질 때까지 보류 |

## Join NEXUS

NEXUS는 배재대학교 재학생과 휴학생이라면 전공과 학년에 관계없이 참여할 수 있습니다.

다음과 같은 학생을 기다립니다.

- 자신의 전공을 실제 프로젝트에 적용해보고 싶은 학생
- 아직 부족해도 다른 사람과 함께 배우고 싶은 학생
- 작은 역할이라도 기한을 지키고 결과를 남길 수 있는 학생
- 코드뿐 아니라 설계·실험·디자인·문서·조사·운영에 참여하고 싶은 학생
- 자신의 아이디어를 직접 프로젝트로 발전시키고 싶은 학생

새로운 프로젝트를 제안할 때는 다음 내용을 함께 정리합니다.

1. 해결하고 싶은 문제
2. 만들고 싶은 첫 결과물
3. 본인이 맡을 역할
4. 필요한 전공과 참여자
5. 첫 4주 동안의 계획
