PAICHAI NEXUS는 배재대학교의 여러 전공 학생들이 함께 문제를 찾고, 각자의 전공을 활용해 **실제로 작동하는 결과물**을 만드는 학생 주도 융합 프로젝트 동아리입니다.

우리는 많은 아이디어를 동시에 벌이기보다 **작은 목표를 정하고, 직접 만들고, 확인하고, 기록하는 것**을 중요하게 생각합니다.

## 2026 Focus

### 🌱 [Smart Seedling AI](https://github.com/paichai-nexus/smart-seedling-ai)

작물 이미지와 환경 데이터를 수집하고, 생육 상태와 이상징후를 관찰하는 스마트팜 연구개발 프로젝트입니다.

2026년 2학기에는 Smart Seedling AI를 NEXUS의 **최우선 프로젝트**로 운영합니다.

## How We Work

1. 작은 목표라도 끝까지 완성합니다.
2. 결과뿐 아니라 배우고 실패한 과정도 기록합니다.
3. 다음 사람이 이어갈 수 있도록 자료를 남깁니다.

```text
문제 발견 → 조사 → 작은 목표 설정 → 제작·실험 → 확인 → 기록
```
